Internal audit sample files (Engagement > Workpapers > Upload workpaper)
Accepted by the app: PDF, JPG, PNG, Word (.doc/.docx), Excel (.xls/.xlsx); 10 MB at most.
valid_*       should upload; open each from the workpaper list and Download to compare.
too_big_11MB.pdf, wrong_type_*     must be refused with the on-screen message.
empty_zero_bytes.pdf, fake_*       carry an allowed type but are not real files. The server only checks the type the browser reports, so they may be ACCEPTED: record what happens (suspected gap).
